# figma-to-code — конвенции проекта

> Детектировано автоматически 2026-09-08 (stack без build-инструментов). Правь под себя.

## Stack
- UI: статический сайт — один `index.html` + `style.css` + `script.js` (vanilla JS, без фреймворка и бандлера). Leaflet для карты, Supabase для данных.
- Разрешение/viewport: десктоп, ширина сайдбара фиксированная (320px в макете; в рантайме есть resize-handle). Карта — на всё окно.
- Префикс shell-команд: нет.
- Кэш-бастинг: `?dev=NN` на `style.css`/`script.js` в `index.html` — бампать `NN` при каждом изменении этих файлов.

## Спецификация
- Расположение спеков: `.agents/figma-to-code/specs/<feature>.md`
- Директория ассетов: `images/ui/` (UI-иконки/эффекты; растровые иконки локаций — `images/icons/`)
- Индекс фич: нет.

## Design system
- Источник токенов в коде: CSS custom properties в `:root` — блок «РЕСКИН» в `style.css` (`--ink-*`, `--parch-*`, `--brass-*`). Значения дублируются inline hex по месту (исторически).
- Токены из макета `haven-map-WIP` (Figma): `ink-{500,600,700}`, `parch-{200,400}`, `brass-{300,500,600,700,800}`, `sidebar-fill`.
- Переиспользуемые компоненты: в этом проекте «компонент» = класс + HTML-хелпер в `script.js` (напр. `iconToggleTextHTML` / `.icon-toggle` со слоями `__fx/__grad/__noise/__line`). Новых абстракций не заводить без запроса.
- Новые токены/ассеты: класть SVG в `images/ui/`, добавлять правила в блок «РЕСКИН» `style.css`; согласовывать в спеке.

## Структура кода
- Всё в трёх файлах. Разметка сайдбара — в `index.html` (`#sidebar` → `#normal-view` / `#edit-marker-view` / `#edit-quest-view`).
- Рендер списков (журнал заданий, дерево провинций, ряды фильтров) — функции в `script.js`, вставляют `innerHTML`.
- Правила рескина живут одним блоком в конце `style.css` («РЕСКИН — Figma node 254:1525»), поверх базовых стилей; значения — из макета, не «магические».

## Команды
- Быстрая проверка: линковки/сборки нет — открыть в браузере, убедиться что нет ошибок в консоли.
- Тесты: нет.
- Запуск с релоадом: `py -m http.server 8791` (см. `.claude/launch.json`, конфиг `haven-map`). Инстанс определяется по занятому порту 8791.

## Скриншот приложения (Фаза 5)
- Метод: Browser pane (preview_start `haven-map` → computer screenshot). Python `http.server` не шлёт `Cache-Control` — для перечитки поднимать `?dev=NN` и/или грузить `/?cb=<ts>` (иначе документ отдаётся из дискового кэша).
- Форсирование состояний для проверки: `document.body.classList.add('is-admin')` + `isAdmin = true` в консоли + перерендер (`renderQuestJournal()`); полноценный админ-режим требует входа через Supabase (недоступно агенту).
- Замечания: SVG-иконки с `feTurbulence` (зерно) тяжело растеризуются при `zoom` — скриншот большой увеличенной области может таймаутить.
